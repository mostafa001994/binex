# سوابق تصمیم معماری (ADR)

ADR دلیل تصمیم‌های پراثر و پیامد آن‌ها را ثبت می‌کند تا با بزرگ‌شدن پروژه دوباره از صفر تصمیم‌گیری نشود.

## فهرست

- [ADR-001: PostgreSQL و Prisma](001-postgresql-and-prisma.md)
- [ADR-002: اجرای Docker](002-docker-runtime.md)
- [ADR-003: مرز Binix و n8n](003-n8n-boundary.md)

وضعیت هر ADR یکی از `proposed`, `accepted`, `superseded` یا `deprecated` است. تغییر تصمیم با ADR جدید و ارجاع به سند قبلی انجام می‌شود.
