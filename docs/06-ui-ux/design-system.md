# اصول UI/UX

## جهت محصول

تجربه عمومی باید اعتماد ایجاد کند و کاربر را به «درخواست مشاوره رایگان» هدایت کند؛ صفحه فروشنده هوشمند CTA اصلی «درخواست دمو» دارد. پنل‌ها باید حس کنترل، شفافیت وضعیت و قابلیت پیگیری بدهند.

## اصول ثابت

- فارسی و RTL پیش‌فرض؛ اصطلاح انگلیسی فقط وقتی معادل دقیق یا شناخته‌شده ندارد.
- شناسه فنی در جریان روزمره برجسته نشود؛ در جزئیات/کپی فنی قابل دسترس باشد.
- هر mutation دارای feedback واضح و حالت disabled هنگام ارسال باشد.
- loading، empty، error و success برای هر صفحه طراحی شود.
- عملیات خطرناک اثر، دامنه و برگشت‌پذیری را پیش از تأیید توضیح دهد.
- Modal طولانی به stepper، section یا صفحه مستقل تبدیل شود.
- جدول موبایل به card/list معنادار تبدیل شود یا ستون‌های اولویت‌دار داشته باشد.

## ناوبری مدیریت

- مدیریت مشتریان: کاربران، کسب‌وکارها، پشتیبانی
- محصول و فروش: سرویس‌ها، پلن‌ها، اشتراک‌ها
- مالی: سفارش‌ها، پرداخت‌ها
- عملیات: اتصال‌ها، راه‌اندازی‌ها، اعلان‌ها
- سیستم: نقش‌ها، گزارش تغییرات، وضعیت سیستم

## دسترس‌پذیری

- ترتیب focus منطقی و focus trap صحیح در modal؛
- label واقعی برای input و نام قابل فهم برای icon button؛
- پشتیبانی کامل keyboard و Escape؛
- contrast مطابق WCAG AA؛
- اعلان تغییر وضعیت با live region؛
- تست در عرض‌های 360، 768، 1280 و 1920 پیکسل.

## معیار بازبینی صفحه

هدف صفحه، CTA اصلی، مسیر برگشت، اولویت اطلاعات، وضعیت‌های غیرعادی، رفتار موبایل، دسترسی keyboard و متن فارسی باید قبل از تأیید بررسی شوند.
